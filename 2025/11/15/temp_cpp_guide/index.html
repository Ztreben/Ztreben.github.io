1️⃣ C语言基础语法

👨‍🏫 开场白：C语言是所有编程的基石。就像学武功要先扎马步一样,学编程要先打好C语言的基础!

1.1 基本数据类型

整型类型 - 装数字的盒子

💭 先来个灵魂拷问:为什么有这么多种整型?

想象你去超市买饮料:

  • 小瓶装(char): 装得少,但便宜(省内存)
  • 中瓶装(int): 最常用,性价比高
  • 大瓶装(long long): 能装更多,但占地方

数据类型也是同样道理!

📊 整型选择速查表

数据范围 推荐类型 原因
≤ int 小数字
≤ int 标准范围
> long long 大数字
两数相乘 long long

❓ 新手常见问题

Q: 什么时候会溢出？怎么避免？

Q: unsigned什么时候用？

  • ✅ 适合:数组下标、计数、位运算
  • ❌ 不适合:可能出现减法变负数的情况

浮点类型 - 装小数的盒子

💭 为什么不能用整数表示所有数字？

想象你要分蛋糕:

  • 3个人分10块 → 每人3.333…块 (无限小数)
  • 计算圆的面积 → π = 3.14159… (无理数)

所以我们需要浮点数!

⚠️ 浮点数大坑警告

�� 记忆口诀

  • 需要小数 → 用double
  • 比较相等 → 用fabs(a - b) < EPS
  • 循环控制 → 用int,不用double
